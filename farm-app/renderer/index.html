Run an AI farm on this machine

This turns this computer into a private LlmOnLan server for your network. Everything installs itself — no terminal, no setup.

  • Downloads its own AI engine (Ollama) and helpers
  • Pulls the gemma4:12b model (~8 GB)
  • Serves chat, web search & document reading to everyone on the LAN
  • Managed from the built-in admin panel

First-time setup needs an internet connection and can take a while.
