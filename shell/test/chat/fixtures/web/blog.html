Quill 6.0 is here: the latest stable version of Quill

By a blogger, 1 March 2024

Quill 6.0 is the latest stable version of the Quill editor. This stable version brings a new plugin system, and the latest stable version is the one every Quill user should install today.

If you want the latest stable Quill, version 6.0 is the stable version to get: the latest stable release of Quill is 6.0, and Quill 6.0 stays the latest stable version until the next release.

We tested the new version of Quill for two weeks on three computers and found it faster than the previous one, with fewer crashes when opening large files.
