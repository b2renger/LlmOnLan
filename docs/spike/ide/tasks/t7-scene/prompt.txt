scene.png in this project is a picture of a 3D scene. Look at it with your image tool, then make index.html that rebuilds the scene with three.js: load three.min.js from this folder with a plain script tag (it defines the global THREE; nothing from the internet), and give the scene the same objects, colours, positions, lights and camera view as closely as you can. Render it once to a 1024 x 640 canvas.
