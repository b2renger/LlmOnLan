# New open models, 2026-11-12 to 2026-11-23: none for our boxes yet

The models released since [MODELS_2026-11-13](MODELS_2026-11-13.md) that could serve a class on one RTX PRO 6000
(96 GB, vLLM, NVFP4) or a DGX Spark: at most ~130B total, a checkpoint that fits, an engine **release** that serves it.
Inkling 2 has its own file ([INKLING_2_MINI_2026-11-23](INKLING_2_MINI_2026-11-23.md); plans ▸ Next 20). A `docs` reader
listed the vendors' Hugging Face repositories by creation date (2026-11-23, about 09:10); the sizes below were checked
with the Hugging Face API the same minute. **Vendor** marks the vendors' own words.

## The answer: nothing fits today

| Model | Released | Size (API) | Why not now |
|---|---|---|---|
| `inclusionAI/LingSante-3.1-air-VL` | 2026-11-19 | 124.8B (5.5B active, vendor), BF16 only, 250 GB, MIT, pictures | Under the size limit, but no official NVFP4 or FP8 (a community W4A16 exists), and its README installs vLLM **from a fork**; no vLLM release names it |
| `tencent/Hy4-flash` (and `-FP8`, 287 GB) | 2026-11-17 | 220.3B (12B active, vendor) | Over the limit; Tencent's own licence |
| `inclusionAI/LingSante-3.1-flash` (and `-MXFP4`), `tencent/Hy4-FP8` | 2026-11-18/22 | 294B to 774B | Over the limit |
| `tencent/WeMM-Video-2B/4B/9B`, `microsoft/Aion-1.0-Instruct-2.3B`, `allenai/LitAgent…-9B` | 2026-11-17/20 | 2–9B | Small, not a class chat model |

No new model from Qwen, Google, NVIDIA, Mistral, DeepSeek, Moonshot, Zhipu, MiniMax, Xiaomi, IBM, Meta, OpenAI, StepFun,
Baidu or Liquid in the window, by their listings (the reader's; not each checked by hand).

## The models we already follow

- **Ripple-65B Preview:** vLLM 0.34.0 (2026-11-16) serves it, BF16 and NVFP4 (#65745), as plans ▸ Next 12 says; no
  final release yet.
- **Qwen3.8, Gemma 4, Nemotron 3.5, Flint:** nothing new from their vendors in the window (vLLM 0.34.0 adds
  Nemotron-3.5-Transcribe, speech only). No official Qwen3.8 NVFP4.
- **Kolibri-1:** its repository changed on 2026-11-19; what changed was not read.

## Next look

LingSante-3.1-air-VL when an official 8- or 4-bit checkpoint and a vLLM release appear (its 124.8B in NVFP4 would be
about 65 GB, leaving little room beside it on a PRO 6000: estimated). The pinned tools' look at each session's start
covers the engine side.
