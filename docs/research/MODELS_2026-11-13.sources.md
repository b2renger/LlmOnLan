# Survey 2/3: the engines (Haiku `docs` reader, 2026-11-12 ~20:15). Sources as given; not yet re-checked.

## vLLM
- No release after 0.33.0 (PyPI final 2026-11-02; 0.32.0 2026-10-18; 0.31.0 2026-10-05). https://pypi.org/project/vllm/#history
  GitHub release titled v0.33.0 but tagged v0.33.0rc3 (tag v0.33.0 → 404). https://api.github.com/repos/vllm-project/vllm/releases/tags/v0.33.0rc3
- 0.33.0 notes: Blackwell kernels (FA4 sparse MLA decode, NVFP4 MoE online re-quant, DeepGEMM MegaMoE NVFP4 experts); no SM120/SM121 named;
  Nemotron-3-Nano NVFP4 torch.compile garbage fix; GLM-5.3-Flash FP8 KV default; pluggable KV dtypes (#52670); lookahead block hashes so
  EAGLE/MTP prefix-cache hits keep their last block (default on); CPU KV offload; sliding-window block tables; spec-dec: FLy policy, DFlash
  no draft-slot reservation, quantized draft lm_head; Medusa + MLP speculator removed (#61701); paused generation → HTTP 503.
- 0.32.0: low-precision KV cache across several GPU generations (summary only).
- SM120/WSL2: community reports only (CUTLASS NVFP4 MoE path garbage → Marlin MoE backend, MTP off; WSL2 NCCL env). vLLM DGX Spark blog
  https://vllm.ai/blog/2026-06-01-vllm-dgx-spark (snippet only).

# Survey 3/3: independent evidence, RAG and code (Haiku `docs` reader, 2026-11-12 ~20:20). Sources as given; not re-checked.

## Headline
- **Long documents: no independent 32k/64k result exists for any model in range** (≤130B total, ≤20B active). Only vendor (NVIDIA RULER 64K)
  and aggregator numbers (BenchLM, DataLearner, llm-stats). LongBench v2's official board stopped 2025-05-06. HELMET, MRCR: not found.
  → our own RAG check (docs/spike/runs/rag_check.mjs) is the only evidence for documents. Confidence in published numbers: low.
- **Code:** independent in-range evidence is thin. Artificial Analysis index (article 2026-04-13, version unstated):
  Qwen3.5 27B (dense) 42, Gemma 4 31B (dense) 39, Qwen3.5 35B-A3B 37, Gemma 4 26B-A4B 31, Nemotron Cascade 2 30B-A3B 28, Nemotron 3 Nano ~24.
  https://artificialanalysis.ai/articles/sub-32b-open-weights . AA v5.0.1 pages: Qwen3.6-35B-A3B no public score; GLM-5.3-Flash 28 (320B/18B, out
  of range); MiMo-V2.6-Flash 27; DeepSeek V4.1 Flash 33 (size not shown).
- **Terminal-Bench 2.0, Vals** (independent, archived 2026-06-04): Qwen 3.6 27B (dense) 44.94 %, Gemma 4 31B 39.33 %, gpt-oss-120b 19.10 %.
  https://www.vals.ai/benchmarks/terminal-bench-2
- Vendor coding numbers: Qwen3.6-35B-A3B SWE-bench Verified 73.4; Qwen3.8-Flash-Next (125B/6B per secondary sources) SWE-bench Pro 62.5;
  Qwen3.8-27B SWE-bench Pro 61.7; Qwen3-Coder-Next (80B/3B) SWE-V 70.6; Nemotron 3.5 Lightning SWE-V 51.56.
